# SeniorNav 初版试用说明

**状态：2026-11-13，版本 0.1.0+1，可试用初版，验收未完成。** 正式首页、路线摘要、本地地点与家属设置已实现。
完整 Debug 与 Release APK 已构建；`flutter analyze` 零问题，Flutter **108 项测试通过**，
原生串行闸门另有 **8 项断言通过**。Flutter + SDK 集成烟测 **4 次串行调用成功**；Release 已覆盖安装到真机，首页五入口和标题三击进入首次 PIN 设置已确认；未代设 PIN 或填入家庭地址。

本版只做老人手机上的出行助手，不包含家属远程管理、位置共享、后台跟踪或云同步。
默认没有保存地点，也不内置私人家庭坐标或演示路线；首次打开后需要家属设置。

## 1. 家属第一次设置

1. 在首页连续点按 **SeniorNav 标题三次**。
2. 设置自己的 **4～6 位数字 PIN**，再输入一次确认。以后进入家属设置需要此 PIN。
3. 阅读位置与地图服务说明，明确同意后再使用地点搜索和路线查询。
4. 选择“回家”或另外一个首页位置，点击“设置地点”；也可以添加“更多地点”。
5. 填写城市与地点名称，点击“搜索地点”。输入文字不会自动查询，查询未结束时不能连点重复发起。
6. 从结果中选择正确地点，应用取得该 POI 的详情。
7. 点击“打开地图核对入口”，在百度地图或地图网页中核对地点与出入口。
8. 返回 SeniorNav，勾选“我已核对地图，确认这是要去的入口”，再点击“保存地点”。
9. 返回首页，保存结果立即生效，不需要重启。

仅输入名称不能保存；没有打开地图并显式确认入口也不能保存。医院、小区等多入口地点要特别核对
老人实际可通行的入口。若页面提示百度未提供导航入口，返回搜索具体大门或出入口；
地点中心坐标不能默认当作入口。确认不对时返回重新搜索、选择，不能为了完成设置直接勾选。

“回家”固定在首页第一位，可以修改地址，不能删除或移走。其他地点可改名称和图标，移动到空余首页位置
或“更多地点”；更多地点可以上移、下移、修改、删除。

## 2. 老人如何使用

1. 首页点击“回家”“去家人家”“医院”“超市”，或进入“更多地点”选择目的地。
2. 第一次查询可能出现 Android 定位权限弹窗。应用只在查询时获取一次前台位置。
3. 等待路线摘要。推荐方式默认选中，也可以按“坐公交”或“走路”切换。
4. 先看总时长和换车提示，再看线路方向、上车站、坐几站、下车站与步行距离。
5. 点击“打开地图导航”。步行优先打开百度步行导航；公交打开百度路线页，可能仍要在百度中选择方案。

摘要供出发前理解路线，实际路线以百度地图为准。超过 5 分钟会提示重新查询；不会自动重复查询。
定位、网络或路线失败时，页面仍保留“打开地图导航”，可以交给百度地图自行定位和规划。

## 3. 查询慢或失败时

超过 5 秒会显示“仍在查询…”，可以等待或打开百度地图。不要连续切页、连点或启动其他探针来催查询。

百度个人认证路线服务的并发上限是 **3**，本 App 使用更保守的规则：

- POI 搜索、详情和路线共用 Dart 与原生串行闸门，最多一条在途检索。
- 公交、步行以及必要的一次少换乘策略补查依次执行；策略补查不是网络失败重试。
- 页面返回或界面超时不会释放尚未确认结束的请求；发起返回 `false` 也可能随后收到回调。
- 发生无法确认结束的情况时停止后续检索，保留地图导航，不自动重试。

若页面提示上一条查询尚未确认结束，请先使用百度地图。需要排查或关闭后重新打开 App 时由人操作；
不要自动循环重启，也不要同时启动 SDK 探针、坐标检查或其他百度检索脚本。

## 4. 地点与隐私

- 常用地点和设置只保存在手机本地 SQLite；当前定位和路线摘要只在内存中，不保存行踪。
- 搜索地点、查询路线时，相应地点或起终点会交给百度服务处理；打开百度后由百度提供导航。
- Android 应用云备份已关闭。更换手机、卸载 App 或清除应用数据后，需要重新设置地点。
- 家属 PIN 只用于防止误改，不代表数据库已经加密，也不是账户密码。
- 不要把含家庭位置的截图、数据库或调试输出放进仓库。提交规则见 [GIT_COMMIT_RULES](../GIT_COMMIT_RULES.md)。

## 5. 构建、覆盖安装与 M0 区分

在仓库根目录执行：

```bash
python3 tools/build_app.py
# 需要发布模式时：
python3 tools/build_app.py --release
```

该脚本从环境变量或 ignored `.env.local` 读取 `BAIDU_ANDROID_AK`，只注入 Android 类型 AK，
正式入口为 `app/lib/main.dart`，不注入私人地点或服务端密钥。

Debug 产物为 `app/build/app/outputs/flutter-apk/app-debug.apk`；Release 产物为同目录下
`app-release.apk`。阶段性基线构建为 57,384,095 字节；后续图标稿构建信息见第 8 节。
可用 `adb install -r <APK 路径>` 覆盖安装以保留本地设置。

M0 URI 探针保留在 `app/lib/m0_probe.dart`，`tools/build_probe.sh` 已改为显式构建此入口，
并会注入本机私人地点。它与正式初版、SDK 探针使用同一个包名，不能共存；不要混用产物或把 M0 包当正式包分享。

## 6. 尚未完成的验收

当前构建和离线测试证明实现可以运行，不等同于老人已经能独立、安全使用。以下仍需继续验证：

- 实际老人阅读摘要、辨认方向和上下车站，以及大字界面的误触情况。
- 户外真实定位精度、不同网络环境、公共地标和常用目的地的入口落点。
- 足量真实查询样本的 p95 延迟、长期稳定性与常见异常恢复。
- 未安装或版本过旧时的完整回退体验：网页无可用起点坐标时，可能仍要求手动选择起点。
- 其他手机系统及百度版本的调起行为；Flyme 可能出现确认框或小窗。

初版暂未对语音播报、关怀版或真实卸载后的完整流程作最终通过结论。
已有证据与未完成项继续记录在 [真机导航测试清单](../m0/真机导航测试清单.md) 和对应 ADR 中。
