# 本目录的图已过期，不要作为 V1 参考

`fig1_plan.*`、`fig2_mock.*` 与 `fig3_guide.png` 都是按**方案 v0.1**（老年人出行导航与家属守护应用）口径画的。

v0.2 已经把定位改成"老年人极简出行决策助手"，并在 §1.4 非目标里明确删除了：

- SOS、防走失、电子围栏、全天候位置共享
- 实时公交到站、上下车提醒、全程语音导航
- 家属 H5 守护页、Traccar 位置上报

这些图里仍然画着上述功能，与现行方案矛盾。图里的地点名称是虚构的（幸福小区、建设路、滨江花园、张阿姨等）或公共地标（芙蓉路、科大东区、148 路），不涉及隐私，但**内容口径已经作废**。

`fig3_guide.png` 稍特殊：它的 V1 部分（首页五个大按钮、摘要页、调起百度地图）与 v0.2 一致，
但右侧「V2 扩展」面板仍画着 v0.2 已删除的「可选的老人位置查看」，示例线路也是示意而非实测。
引用它时只能取 V1 那一半，且要注明 V2 面板作废。

现行口径以 `docs/plan/SeniorNav_项目初步方案_v0.2.md` 为准，摘要页的实际渲染样张见 `docs/m0/纸面摘要样张.md`。

保留而不删除，是因为它们记录了 v0.1 的范围设想，对理解 v0.2 为什么砍掉一半功能有用。要对外分享或写进任何交付物之前，必须按 v0.2 重画。
