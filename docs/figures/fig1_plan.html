SeniorNav · 方案一图看懂

老年人出行导航 ｜ 不重做地图，只把「常去的地方」变成一次点击
方案 v0.1　·　2026-11-11
状态：方向已定，M0 待真机验证
V1 · 先交付

家属配一次，老人点一下

纯本机、无账号、无服务器
  • 家属在老人手机上录入 ≥5 个常去地点（家、医院、菜市场、子女家），逐一核对地图位置
  • 老人打开 App：顶部一个巨大的「回家」，下面是大卡片列表
  • 点地点 → 百度地图直接打开正确目的地的路线
  • 底部「步行 / 公交」一键切换，「联系家人」直接拨号
没有网络也能点：地图和拨号都由手机自带应用接管。
M0 · 先验证（1–2 天）

四个问题，真机问百度

答不上来就不写 V1 界面，避免白做
  • 步行能不能一键进导航（walknavi）
  • 起点怎么给：省略 / 我的位置 / 坐标
  • 手机 GPS 起点 + 百度终点，偏移几米
  • 公交要几次点击才到某条线路
结论写进 docs/m0/ 并录屏。M0 不过，就换方案（如百度 Android SDK），而不是回头改界面。
