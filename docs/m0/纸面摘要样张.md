# M0 纸面摘要样张

方案 v0.2 §10 M0 任务 3 要求「按本方案 3.3 做纸面摘要，找实际老人读一遍，记录能否复述线路/方向/下车站」。本文件是那一次朗读测试的材料。

样张由 `app/tool/render_paper_summary.dart` 从 `app/test/fixtures/` 下真实录制的百度响应生成，**不是手抄**。手抄会顺手把文案改顺，测出来的是人写的句子而不是渲染器的输出。

重新生成：

```bash
cd app && dart run tool/render_paper_summary.dart
```

## 阅读这份样张前要知道的两件事

1. **录制时刻是凌晨 02:00**，所以每张样张都带「首班 …，现在可能还没发车」告警。这条告警是必须的——实测百度**不校验运营时间**，凌晨查询照样返回首班 06:12 的地铁方案（ADR 0002 §2.9）。正式测试请在真实出行时段重录 fixture，告警就不会出现。
2. 三条线路的起终点全是公共地标（火车站、地铁站、公园、公立医院），符合 `GIT_COMMIT_RULES` §3.1。**给老人做正式测试时应换成真实目的地**，届时在本机临时录制 fixture，不要提交进仓库。

```text
去医院 · 坐公交（推荐）

① 步行约 710 米 → 大蜀山站(C口)
② 坐 轨道交通2号线（开往 撮镇方向），9 站，四牌楼站下车
③ 步行约 590 米到终点

⚠ 轨道交通2号线 首班 06:00，现在可能还没发车
```

```text
去医院 · 走路

约 3 小时 13 分钟 · 约 12.8 公里

```

查询时间 02:00｜路线以百度地图为准｜数据来源：百度地图

> 这一张值得特别注意：百度按 `tactics_incity=2`（少步行）返回时，把 **87.6 分钟、1 次换乘**的 85 路+320 路方案排在第 1 位，而 **39.9 分钟、0 次换乘**的轨道交通 2 号线排在第 5 位。摘要页按 §4.4 重排后选中的是后者。也就是说，如果直接拿百度的第一条渲染，老人会看到一个换乘更多、慢一倍的方案（ADR 0002 §2.7）。

## 样张 3｜去地铁站

合肥南站 → 合肥南站-地铁站（95 米）　｜　自动推荐：走路

```text
去地铁站 · 坐公交

这段路没有公交方案
```

```text
去地铁站 · 走路（推荐）

约 1 分钟 · 约 100 米
```

查询时间 02:00｜路线以百度地图为准｜数据来源：百度地图

> 这一张覆盖 §3.7 的一个边界：百度返回 `status == 0` 且 `routes` 为空，是**成功响应**，意思是这段路没有公交方案。如果当成接口失败处理，老人会看到「暂时查不到路线」，而正确答案是「走路」（ADR 0002 A6）。
