# 桌面图标：相伴回家

小房子前，一对银发老年夫妻微笑相伴。当前采用用户提供的完整暖色插画，保留原图的人物、房屋与绿植构图。

- `home-portrait.png`：当前使用的完整插画副本，保存时去除文件元数据。
- `launcher-review.png`：圆形、圆角方形及小尺寸检查图。

从仓库根目录执行 `python3 tools/render_launcher.py` 可重建预览和 Android 资源，仅需 Python Pillow。脚本离线运行，只去除与图片外角相连的黑色底，保留人物内部的深色头发与衣服。

1024 像素独立预览写入已忽略的 `app/build/artwork/launcher-preview.png`，不重复纳入版本控制。

Android 8 及以上使用 108dp 自适应前景层和独立奶油色底，完整插画缩放到中央 72dp 视口；脸部与屋顶顶点保留在安全范围内，外围肩部、绿植会随系统形状裁切。旧系统使用五档 `mipmap` PNG。已检查圆形、圆角方形与 48px 缩略效果。

本次为本地图像处理，没有调用生成式图像服务。原始半身图没有可见的搀扶手臂，当前保留原图姿态。
